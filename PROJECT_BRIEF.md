# Project Brief

## Product

A web-based interactive scientific learning environment where students learn by manipulating and experimenting with 3D simulations.

This is not a 3D model gallery.

## Core Experience

Every learning experience should combine:

- 3D model/environment
- interactive objects
- real-time simulation
- adjustable variables
- measurements
- experiments
- visual feedback
- contextual explanations
- optional AI tutor

## Initial Subjects

Phase 1:

- Physics

Phase 2:

- Chemistry

Phase 3:

- Biology

Future:

- Astronomy

- Mathematics

1. Projectile Motion
2. Pendulum

4. Optics
5. Gravity

## Product Principles

### Experiment First

Students should learn by changing variables and observing outcomes.

### Simulation First

The simulation should be the primary interface, not a dashboard surrounding a 3D object.

### Scientific Accuracy

Equations, assumptions, units and calculations must be explicit and testable.

### Extensibility

New simulations must be addable through reusable engine APIs.

### Performance

The platform must remain responsive on normal student laptops.

## First Vertical Slice

Build Projectile Motion completely before building all other simulations.

It must support:

- velocity
- launch angle
- gravity
- launch height
- optional air resistance
- trajectory
- velocity vector
- acceleration vector
- gravity vector
- range
- maximum height
- flight time
- start/pause/reset
- experiment recording
- measurement
- contextual explanation
